# README visual direction

- Audience: Codex users who delegate local coding work to Antigravity.
- Value: see quota, resets and explicitly reported task metrics inside Codex.
- Proof: screenshots of the actual panel component rendered with example data; not Codex shell captures.
- First action: clone the repository, install dependencies, register its local marketplace, open AGY 用量.
- Palette: graphite `#1c1d1f`, warm white `#f5f5f1`, sage `#a9b9a3`, muted gray `#b7b8bc`.
- Typography: system sans serif; restrained monospace for technical labels.
- Shape: 18–22 unit corners, thin rules, generous whitespace.
- Motif: the panel's weekly and five-hour quota bars.
- Composition: calm technical title, large theme-aware proof, Markdown commands and limitations.
- Assets: static, deterministic SVG; no generated art or animation.
